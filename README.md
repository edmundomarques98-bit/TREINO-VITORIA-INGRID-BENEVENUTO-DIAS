# Treino Vitória Ingrid Benevenuto Dias

Site mobile-first para acompanhamento do treino semanal, com:
- foto personalizada no topo;
- divisão por dias;
- séries com marcação individual;
- campo para registrar carga;
- progresso semanal;
- histórico local de séries concluídas.

Os dados são salvos no navegador via localStorage.
